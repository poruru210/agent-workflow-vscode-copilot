01 / Bootstrap

Compactで終えてよいかを最初に判定

短いread-only回答だけは軽量化。それ以外は実質作業の前にNormal workflowへ昇格します。

全条件を
肯定できる？

短時間 / 単一目的 / read-only / 低risk / 実装・test・audit・delegationなし / volatile identityなし / material harmなし

YES → Compact

  1. 目的・質問
  2. 対象・正本
  3. 取得時刻/version
  4. 許可scope
  5. 結論と限界

durable stateやsubagentを作らず終了。

NO / 不確実 → Normal

  1. Work Definition
  2. Risk / Plan
  3. Baseline
  4. 作業種別分岐
  5. Snapshot / Audit / Test
  6. Completion

途中でwrite・長期化・delegation・material riskが出てもNormalへ昇格。

04 / Dynamic Model Routing

役割とモデルを分離する

Custom Agentにはmodelを固定せず、delegation直前にjob requirementと現在利用可能なmodelから最低十分な候補を選びます。

① Job Leasefamily / modality / context / tools / ambiguity / harm / independence
② #workflowModelslive catalogを取得
③ Hard Capability Filter不適合候補を除外
④ Minimum Sufficient Set必要能力を満たす最小側
⑤ Independence / Cost相関blind spot / latency / comparable evidence
⑥ runSubagent(model=…)開始前にjob/model/reasoning/理由を表示

Live Model Catalog — 順位表ではない

候補 Avendor / family / version / maxInputTokens

B
候補 Bidentity / context capacity
適合

除外
APIが返さないものを推測しない： cost tier / reasoning level / modality・tool suitability / latency / quality ranking。必要ならVS Code現行表示・provider公式説明・実行結果で補います。

06 / Hooks

監査境界を補助的に強制

Hookは正しさの証拠ではなく、read-only enforcement、checkpoint、job状態記録、未解消claim警告の補助です。

SessionStartdurable stateを再取得。Compactならworkspaceを汚さない。
PreToolUseaudit phaseのwriteをdeny。未証明commandはask。
SubagentStartstateless lease boundaryを注入。
SubagentStopjob runtimeをterminal化。
PreCompactcontext圧縮前checkpoint。
Stopmandatory claim残存時に完了警告。
07 / Evidence Architecture

「何を証明する記録か」を分離

根因、検出漏れ、介入、変更安全、停止合成、検証モデルを別packetとして管理し、Evidence Dependency Mapで再利用/失効を制御します。

08 / Deployment & CI

workflow正本は1セット。配置先だけが違う

Repository/Globalの二重ソースは持ちません。CIでworkflow ZIPとVSIXを生成します。

Repository配置

workflow ZIPの中身を対象repoの `.github/` へ。

<repo>/.github/ ├─ agents/ ├─ skills/ ├─ hooks/ ├─ instructions/ └─ agent-workflow/

Global配置

同じworkflow ZIPの中身を `~/.copilot/` へ。

~/.copilot/ ├─ agents/ ├─ skills/ ├─ hooks/ ├─ instructions/ └─ agent-workflow/
Model Catalog Extension： `extension/src` を正本としてCIでVSIX化し、VS Codeの Extensions: Install from VSIX... で導入します。`.agent-workflow/` はインストール先ではなくworkspace-local runtime stateです。

09 / Completion

テストPASSだけでは完了しない

主目的、変更安全性、identity、独立反証まで同時に閉じて初めてGoです。

目的

  • 正常成功経路PASS
  • 最低必須成果PASS
  • 必須受入PASS
  • 禁止代替結果へ逃げない

変更安全

  • planned / actual delta
  • preservation contract
  • impact cone / cut proof
  • material failure処分

証拠・監査

  • C0
  • 成果鍵 + 独立反証鍵
  • U0→U1 / identity
  • Early + Final Audit
すべて閉じた時だけ Completion / Go
